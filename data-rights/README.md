# 数权 · 数据产权与数据集交易综合数据库

此目录是 GitHub Pages 前端。`index.html` 是可独立运行的构建产物；`source/` 是可编辑的源代码。要重新构建，请在 `source` 目录安装依赖并运行 `npm run build`，然后提交生成的上一级 `index.html`。

AI 问答请求发送至独立的服务端接口，服务端代码见 `ai-service/`。接口由网站所有者在托管平台上配置 `DEEPSEEK_API_KEY` 密钥；不要将密钥放入仓库、前端或此文件。接口包含每日总量和每位访客每分钟的调用上限。接口状态可在网页的 AI 研究助手中查看。

资料为公开来源首批样本；制度信息、来源和全文可用性以具体条目标注为准，不能视为完整穷尽。
