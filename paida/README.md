# 拍档 PAIDANG · 产品官网

拍档 Android v0.6.0 的产品介绍与交互演示。沿用深绿色与奶油白视觉、原创场景插画和动画人物，不使用真人照片。

## 主要内容

- 首页重点介绍「AI 现场指导」，区分可直接对同伴说的姿势口令与拍摄者的取景提示。
- 三个动画场景可切换，支持人物入镜、换推荐、细发光轮廓、九宫格、距离调整和拍后示例评估。
- 介绍 Android 版的 AI 自动变焦、3:4 / 1:1 / 9:16 照片比例、倍率按钮、滑杆和双指缩放。
- 手机拍法灵感按场景、光线、风格和已确认道具提供本地规则建议；口令可以单独复制。
- 手机摄影课堂保留 6 个视频、3 本书、6 份指南和 20 条规则，以及每个来源的实际研读范围。
- FAQ 说明本地保存、单帧图片云端传输、Windows 代理配置、自动变焦与真机验证范围。

## 演示范围

网站是无依赖、无后台的静态 HTML / CSS / JavaScript。网页不调用设备摄像头、不请求 DeepSeek 或其他模型、不上传照片，也不声称当前展示为模型生成结果。相机动画使用预设动作和口令；拍后评估基于示例人物的几何范围。网页不能用来验证 Android 识别效果、真实焦距或物理距离。

Android 云端功能需要配置电脑端代理和有效模型 API；真实模型结果与不同手机的变焦表现仍待真机确认。动画图库只是参考，云端生成协议不以 12 个姿势编号限制输出。

当前 APK 通过项目内测交付，仓库尚未发布公开安装包；网站不提供虚假下载链接，也不暴露会话文件地址、API 密钥或签名密钥。
